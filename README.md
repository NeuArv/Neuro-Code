# Neuro-Code

Exercise notebook for the Neural Computation course (GSN-LMU): computational function of biological units.

## Contents

- `Excersise_01.ipynb` - simulation of the Izhikevich neuron, utility functions, onset/offset detection, noise robustness.

## Requirements

- Python 3
- `numpy`, `matplotlib`, `jupyter`

## Usage

```bash
pip install numpy matplotlib jupyter
jupyter notebook Excersise_01.ipynb
```
